# Handy Hub Store

Responsive green-themed Handy Hub product catalogue for kitchen appliances, watches, dresses and kids' toys.

- Product search, category filters and price sorting
- Product badges and stock status
- Supabase Auth admin login and product management
- Supabase database with Row Level Security
- Supabase Storage for product images
- WhatsApp product enquiries

Read [HANDY-HUB-SETUP.md](HANDY-HUB-SETUP.md) before launch. Run [supabase-setup.sql](supabase-setup.sql) in Supabase and grant the administrator user before using Admin Portal.
